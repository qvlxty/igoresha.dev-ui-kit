### Проверка и подбор контраста

Контраст считается воспроизводимым Node.js-скриптом
`scripts/check-theme-contrast.mjs` по формуле WCAG:

1. Каждый sRGB-канал переводился из диапазона `0–255` в `0–1`.
2. Канал линеаризовался: `c / 12.92` при `c <= 0.04045`, иначе
   `((c + 0.055) / 1.055) ^ 2.4`.
3. Относительная яркость считалась как
   `0.2126R + 0.7152G + 0.0722B`.
4. Итоговое отношение: `(Llighter + 0.05) / (Ldarker + 0.05)`.
